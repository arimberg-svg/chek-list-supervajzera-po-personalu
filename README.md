# Чек-лист супервайзера по персоналу

Полный лист: дела супервайзера и разбор всех должностей розницы на точке.

1. Дела супервайзера по персоналу
2. Вход на визит
3. СПК
4. Продавец-консультант (ПК)
5. Работник торгового зала (РТЗ)
6. Кассир
7. Кладовщик
8. МОП, стол заказов и юрлица
9. Итог визита
